# kaplay-core

Modular KAPLAY engineering skill for reusable game-development guidance.

## Why this skill exists

KAPLAY projects drift quickly when scene structure, sprite animation conventions, and event usage are not standardized. This skill centralizes those rules into reusable reference and recipe files.

## Structure

- `SKILL.md`: concise entrypoint and execution rules
- `references/`: distilled KAPLAY docs by topic
- `recipes/`: project-ready implementation patterns
